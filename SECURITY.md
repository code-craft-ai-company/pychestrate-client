# Security policy

Please report security problems **privately**, not in a public issue.

Use GitHub's private vulnerability reporting: open this repository's **Security** tab, choose **Report a vulnerability**, and describe what you found. Only the maintainers can see the report.

Please include the version or commit, what an attacker could do, and the smallest steps that reproduce it. Please do not publish details until the problem has been fixed.

Anything that is not a security problem (a bug, a question, a feature request) belongs in a normal issue; see [CONTRIBUTING.md](CONTRIBUTING.md).
