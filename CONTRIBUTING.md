# Contributing

This project is **source-available**, not open source. The source is published so that you can read it and use it under the terms in [LICENSE.md](LICENSE.md).

## Issues are the only contribution we accept

Bug reports, questions about how something behaves, and feature requests are welcome in the **Issues** tab. A good issue says what you did, what you expected and what happened instead, with the version or commit and your operating system.

**We do not accept pull requests or other code contributions.** Pull requests are limited to the maintainers, and one that arrives anyway will be closed without review.

Security problems are the exception: report them privately as described in [SECURITY.md](SECURITY.md), not as an issue.
